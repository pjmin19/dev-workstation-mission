CODYSSEY / DEVELOPMENT WORKSTATION

내 컴퓨터에서 시작하는
개발 워크스테이션

Dockerfile로 만든 이미지 안에서 NGINX가 이 웹페이지를 제공합니다. 브라우저가 이 화면을 받았다면, 호스트의 포트와 컨테이너의 웹 서버가 연결된 것입니다.

NGINX 정적 웹페이지
01 · IMAGE

실행 환경을 묶기

공식 NGINX 이미지를 바탕으로 이 페이지를 복사합니다. 이미지를 다시 실행해도 같은 콘텐츠를 제공합니다.

02 · PORT

브라우저와 연결하기

PC의 포트를 컨테이너 내부 80번 포트에 연결합니다. 실행 로그와 주소창을 함께 확인합니다.

03 · STORAGE

변경과 데이터를 확인하기

바인드 마운트로 파일 변경을 확인하고, 별도 볼륨으로 컨테이너 삭제 후 데이터가 남는지 실습합니다.

요청이 도착하는 경로
브라우저 → PC의 공개한 로컬 포트 → 컨테이너의 80번 포트 → index.html
미션 1 실습용 페이지입니다. 실제 실행 명령, 검증 결과와 작업 지원 범위는 GitHub 저장소의 README와 evidence에서 확인할 수 있습니다.
